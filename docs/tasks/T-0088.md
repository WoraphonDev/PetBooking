1. หน้าจอ C-45 บัญชีของฉัน: อุปกรณ์ที่ล็อกอิน แจ้งเตือน และ LINE
2. ยังไม่ทำส่วน/ปุ่มที่ใช้ endpoint ต่อไปนี้ (มี task ต่อยอดภายหลัง): staffMe.pushSubscribe, staffMe.pushUnsubscribe, staffMe.linkLine
3. สร้างทุก section/field ตามตาราง 06 ครบทุกแถว: โหมด (แสดง/กรอก/แก้), แหล่งข้อมูล table.column → ฟิลด์ใน DTO ของ endpoint ที่โหลด, UI/รูปแบบ, กติกา
4. ปุ่ม: แสดงตามเงื่อนไข 'แสดงเมื่อ' และทำตาม 'หลังสำเร็จ'
5. ข้อความไทยใน messages/th/C-45.json; ป้าย enum ผ่าน enumLabel()
6. component test: render ด้วย mock API (msw หรือ mock ของ api.ts) — ตรวจว่าทุกป้ายฟิลด์ในตาราง 06 ปรากฏ และปุ่มเรียก endpoint ที่ถูกต้อง
