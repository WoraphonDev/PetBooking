## Contract (คัดจาก 05 — ชื่อฟิลด์/ชนิด/บังคับ ต้องตรงทุกตัว)

**`staffMe.linkLine`** — `POST /api/v1/staff/me/line-link` · สิทธิ์ `staff` roles `OFS`

Request body:

| field | type | req | maps to | validation |
|---|---|---|---|---|
| `idToken` | string | ✓ | staff_user.line_user_id | LINE ID token |

Response: `StaffMe` — ดูฟิลด์ DTO ที่ anchor `dto-<Name>` ใน 05
Errors: `LINE_TOKEN_INVALID`, `EMAIL_TAKEN`

**`staffMe.pushSubscribe`** — `POST /api/v1/staff/me/push-subscriptions` · สิทธิ์ `staff` roles `OFS`

Request body:

| field | type | req | maps to | validation |

| `endpoint` | string | ✓ | web_push_subscription.endpoint | https URL |
| `p256dh` | string | ✓ | web_push_subscription.p256dh |  |

Response: `204`
ผลที่ต้องเกิด:
- upsert ตาม endpoint, ล้าง disabled_at
