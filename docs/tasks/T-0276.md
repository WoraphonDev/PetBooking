## Contract (คัดจาก 05 — ชื่อฟิลด์/ชนิด/บังคับ ต้องตรงทุกตัว)

**`stays.changeRoom`** — `PATCH /api/v1/staff/stays/{stayId}/room` · สิทธิ์ `staff` roles `OF`

Request body:

| field | type | req | maps to | validation |
|---|---|---|---|---|
| `roomUnitId` | uuid | ✓ | stay.room_unit_id | ประเภทเดียวกัน หรือประเภทอื่นพร้อม keepPrice |

Response: `StayCard` — ดูฟิลด์ DTO ที่ anchor `dto-<Name>` ใน 05
Errors: `ROOM_TAKEN`
ผลที่ต้องเกิด:
- ราคาไม่เปลี่ยน (snapshot) เว้นแต่ส่ง repriceToType=true

**`stays.addAddon`** — `POST /api/v1/staff/stays/{stayId}/addons` · สิทธิ์ `staff` roles `OF`

Request body:

| field | type | req | maps to | validation |
|---|---|---|---|---|
| `serviceId` | uuid | ✓ | stay_addon.service_id | scope hotel, is_addon |
| `quantity` | int |  | stay_addon.quantity | default 1 / per_day = nights |

Response: `StayDetail` — ดูฟิลด์ DTO ที่ anchor `dto-<Name>` ใน 05

**`stays.removeAddon`** — `DELETE /api/v1/staff/stay-addons/{stayAddonId}` · สิทธิ์ `staff` roles `OF`

Response: `StayDetail` — ดูฟิลด์ DTO ที่ anchor `dto-<Name>` ใน 05
