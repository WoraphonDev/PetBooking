## Contract (คัดจาก 05 — ชื่อฟิลด์/ชนิด/บังคับ ต้องตรงทุกตัว)

**`stations.list`** — `GET /api/v1/staff/stations` · สิทธิ์ `staff` roles `OFS`

Response: `object[] groom_station.*`

**`stations.upsert`** — `PUT /api/v1/staff/stations` · สิทธิ์ `staff` roles `O`

Request body:

| field | type | req | maps to | validation |
|---|---|---|---|---|
| `stations[].id` | uuid |  | groom_station.id | ไม่ส่ง = สร้างใหม่ |
| `stations[].name` | string | ✓ | groom_station.name | 1–30 |
| `stations[].sortOrder` | int | ✓ | groom_station.sort_order |  |
| `stations[].status` | enum:record_status | ✓ | groom_station.status |  |

Response: `204`

## Test cases ที่ต้องมี (integration, PGlite)

**stations.list** (GET `/api/v1/staff/stations`)
  - happy path: response ตรง schema `StationsListResponse` และค่าที่บันทึกใน DB ตรงกับ 'maps to' ของแต่ละฟิลด์
  - ฟิลด์บังคับขาด/ผิดรูปแบบ → `VALIDATION_FAILED`
  - ข้อมูลของ organization อื่น → `NOT_FOUND`
**stations.upsert** (PUT `/api/v1/staff/stations`)
  - happy path: response ตรง schema `StationsUpsertResponse` และค่าที่บันทึกใน DB ตรงกับ 'maps to' ของแต่ละฟิลด์
  - ฟิลด์บังคับขาด/ผิดรูปแบบ → `VALIDATION_FAILED`
  - role front_desk/staff → `FORBIDDEN`
  - ข้อมูลของ organization อื่น → `NOT_FOUND`
