**`daycare.list`** — `GET /api/v1/staff/daycare-visits` · สิทธิ์ `staff` roles `OFS`

Query:

| field | type | req | maps to | validation |
|---|---|---|---|---|
| `date` | date | ✓ |  |  |

Response: `DaycareVisitItem[]` — ดูฟิลด์ DTO ที่ anchor `dto-<Name>` ใน 05

**`daycare.check_in`** — `POST /api/v1/staff/daycare-visits/{visitId}/check-in` · สิทธิ์ `staff` roles `OF`

Response: `DaycareVisitItem` — ดูฟิลด์ DTO ที่ anchor `dto-<Name>` ใน 05

State: `daycare_visit:reserved→checked_in`

## Test cases ที่ต้องมี (integration, PGlite)

**daycare.list** (GET `/api/v1/staff/daycare-visits`)
  - happy path: response ตรง schema `DaycareListResponse` และค่าที่บันทึกใน DB ตรงกับ 'maps to' ของแต่ละฟิลด์
  - ฟิลด์บังคับขาด/ผิดรูปแบบ → `VALIDATION_FAILED`
  - ข้อมูลของ organization อื่น → `NOT_FOUND`
**daycare.check_in** (POST `/api/v1/staff/daycare-visits/{visitId}/check-in`)
  - happy path: response ตรง schema `DaycareCheckInResponse` และค่าที่บันทึกใน DB ตรงกับ 'maps to' ของแต่ละฟิลด์
  - error `VACCINE_REQUIRED`
  - error `STATUS_NOT_ALLOWED`
  - ฟิลด์บังคับขาด/ผิดรูปแบบ → `VALIDATION_FAILED`
  - role staff → `FORBIDDEN`
  - ข้อมูลของ organization อื่น → `NOT_FOUND`
  - state: `daycare_visit:reserved→checked_in` + insert booking_event (ถ้าเป็น booking/child) + สถานะต้นทางผิด → `INVALID_TRANSITION`
**daycare.check_out** (POST `/api/v1/staff/daycare-visits/{visitId}/check-out`)
  - happy path: response ตรง schema `DaycareCheckOutResponse` และค่าที่บันทึกใน DB ตรงกับ 'maps to' ของแต่ละฟิลด์
  - error `STATUS_NOT_ALLOWED`
  - ฟิลด์บังคับขาด/ผิดรูปแบบ → `VALIDATION_FAILED`
  - role staff → `FORBIDDEN`
  - ข้อมูลของ organization อื่น → `NOT_FOUND`
  - state: `daycare_visit:checked_in→checked_out` + insert booking_event (ถ้าเป็น booking/child) + สถานะต้นทางผิด → `INVALID_TRANSITION`
