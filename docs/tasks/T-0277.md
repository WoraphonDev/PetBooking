## Contract (คัดจาก 05 — ชื่อฟิลด์/ชนิด/บังคับ ต้องตรงทุกตัว)

**`stays.changeDates`** — `PATCH /api/v1/staff/stays/{stayId}/dates` · สิทธิ์ `staff` roles `OF`

Request body:

| field | type | req | maps to | validation |
|---|---|---|---|---|
| `checkInDate` | date |  | stay.check_in_date | เฉพาะ reserved |
| `checkOutDate` | date | ✓ | stay.check_out_date | > checkIn |

Response: `StayCard` — ดูฟิลด์ DTO ที่ anchor `dto-<Name>` ใน 05
Errors: `ROOM_TAKEN`, `PET_ALREADY_BOOKED`
ผลที่ต้องเกิด:
- nights/room_total ใหม่ (nightly เดิม); add-on per day ปรับ quantity
- checked_in → สร้าง/ลบ care_task ส่วนต่าง
