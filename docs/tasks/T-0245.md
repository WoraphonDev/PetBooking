# T-0245 · Notification templates (customer, M4): ready_for_pickup, report_card, receipt, next_groom_reminder

## Steps

1. `customer.ready_for_pickup`: ช่องทาง line_push, ตัวแปร petName, reportCardUrl, balance, ข้อความ: {petName}อาบน้ำตัดขนเสร็จแล้ว มารับได้เลยค่ะ ✨
{reportCardLine}
ยอดชำระ {balance}
2. `customer.report_card`: ช่องทาง line_push, ตัวแปร petName, reportCardUrl, ข้อความ: Report card ของ{petName} 📋
{reportCardUrl}
3. `customer.receipt`: ช่องทาง line_push, ตัวแปร receiptNo, total, receiptUrl, ข้อความ: ใบเสร็จ {receiptNo} ยอด {total}
{receiptUrl}
4. `customer.next_groom_reminder`: ช่องทาง line_push, ตัวแปร petName, dueDate, bookUrl, ข้อความ: ครบรอบอาบน้ำตัดขนของ{petName}แล้ว ({dueDate}) 🛁
จองคิว: {bookUrl}
5. LINE: Flex Message แบบเรียบ (ข้อความ + ปุ่มลิงก์ LIFF) + altText = บรรทัดแรก; Web Push: title/body/url; email: subject + text
6. เงิน/วันที่ในข้อความใช้ R-31
