## Contract (คัดจาก 05 — ชื่อฟิลด์/ชนิด/บังคับ ต้องตรงทุกตัว)

**`liff.reschedule`** — `POST /api/v1/liff/{branchSlug}/bookings/{bookingId}/reschedule` · สิทธิ์ `customer`

Request body:

| field | type | req | maps to | validation |
|---|---|---|---|---|
| `appointmentId` | uuid | ✓ | groom_appointment.id |  |
| `startsAt` | datetime | ✓ | groom_appointment.starts_at | R-04 |
| `groomerId` | uuid |  | groom_appointment.groomer_id |  |

- booking.reschedule_count + 1
