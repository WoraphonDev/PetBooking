# T-0190 · Notification templates (customer, M3): booking_received, booking_confirmed, booking_declined, booking_cancelled, booking_rescheduled, deposit_confirmed

## Steps

1. `customer.booking_received`: ช่องทาง line_reply|line_push, ตัวแปร shopName, bookingNo, summary, depositAmount, holdExpiresTime, bookingUrl, ข้อความ: ได้รับการจอง {bookingNo} แล้ว 🐾
{summary}
{depositLine}
ดูรายละเอียด: {bookingUrl}
2. `customer.booking_confirmed`: ช่องทาง line_reply|line_push, ตัวแปร bookingNo, summary, dateTime, shopName, mapUrl, bookingUrl, ข้อความ: ยืนยันการจอง {bookingNo} ✅
{summary}
📅 {dateTime}
แผนที่: {mapUrl}
3. `customer.booking_declined`: ช่องทาง line_push, ตัวแปร bookingNo, reason, refundLine, ข้อความ: ขออภัย ร้านไม่สามารถรับการจอง {bookingNo} ได้
เหตุผล: {reason}
{refundLine}
4. `customer.booking_cancelled`: ช่องทาง line_push, ตัวแปร bookingNo, reason, moneyLine, ข้อความ: การจอง {bookingNo} ถูกยกเลิก
{reason}
{moneyLine}
5. `customer.booking_rescheduled`: ช่องทาง line_push, ตัวแปร petName, oldDateTime, newDateTime, ข้อความ: นัดของ{petName}ถูกเลื่อน
จาก {oldDateTime}
เป็น {newDateTime}
6. `customer.deposit_confirmed`: ช่องทาง line_push, ตัวแปร bookingNo, amount, ข้อความ: ได้รับมัดจำ {amount} สำหรับ {bookingNo} แล้ว ขอบคุณค่ะ
7. LINE: Flex Message แบบเรียบ (ข้อความ + ปุ่มลิงก์ LIFF) + altText = บรรทัดแรก; Web Push: title/body/url; email: subject + text
8. เงิน/วันที่ในข้อความใช้ R-31
