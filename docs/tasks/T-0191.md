# T-0191 · Notification templates (customer, M3): slip_rejected, hold_expired, reminder_24h, no_show, balance_link, vaccine_rejected

## Steps

1. `customer.slip_rejected`: ช่องทาง line_push, ตัวแปร bookingNo, reason, newDeadline, payUrl, ข้อความ: สลิปของ {bookingNo} ยังไม่ผ่านการตรวจ: {reason}
กรุณาส่งใหม่ภายใน {newDeadline}
{payUrl}
2. `customer.hold_expired`: ช่องทาง line_push, ตัวแปร bookingNo, bookAgainUrl, ข้อความ: หมดเวลาชำระมัดจำ {bookingNo} คิวถูกปล่อยแล้ว
จองใหม่: {bookAgainUrl}
3. `customer.reminder_24h`: ช่องทาง line_push, ตัวแปร petName, dateTime, service, bookingUrl, ข้อความ: พรุ่งนี้ {dateTime} มีนัด{service}ของ{petName} 🐶
เลื่อน/ยกเลิก: {bookingUrl}
4. `customer.no_show`: ช่องทาง line_push, ตัวแปร petName, moneyLine, bookAgainUrl, ข้อความ: วันนี้ไม่พบ{petName}ตามนัด {moneyLine}
นัดใหม่ได้ที่ {bookAgainUrl}
5. `customer.balance_link`: ช่องทาง line_push, ตัวแปร amount, payUrl, ข้อความ: ยอดคงเหลือ {amount} ชำระผ่าน PromptPay: {payUrl}
6. `customer.vaccine_rejected`: ช่องทาง line_push, ตัวแปร petName, vaccineName, reason, petUrl, ข้อความ: หลักฐานวัคซีน {vaccineName} ของ{petName}ยังไม่ผ่าน: {reason}
ส่งใหม่: {petUrl}
7. LINE: Flex Message แบบเรียบ (ข้อความ + ปุ่มลิงก์ LIFF) + altText = บรรทัดแรก; Web Push: title/body/url; email: subject + text
8. เงิน/วันที่ในข้อความใช้ R-31
