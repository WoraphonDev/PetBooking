## Steps

1. `customer.stay_checked_in`: ช่องทาง line_push, ตัวแปร petName, roomCode, updatesUrl, ข้อความ: {petName}เช็คอินเรียบร้อย ห้อง {roomCode}
ติดตามรูปน้องได้ที่ {updatesUrl}
2. `customer.stay_update`: ช่องทาง line_push, ตัวแปร petName, updatesUrl, ข้อความ: อัปเดตวันนี้ของ{petName} 📸 {updatesUrl}
3. LINE: Flex Message แบบเรียบ (ข้อความ + ปุ่มลิงก์ LIFF) + altText = บรรทัดแรก; Web Push: title/body/url; email: subject + text
4. เงิน/วันที่ในข้อความใช้ R-31
