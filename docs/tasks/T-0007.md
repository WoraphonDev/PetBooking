## Steps

1. `withStaff(key, schemas, fn)` → Next.js handler: session จาก cookie → ctx (org suspended → FORBIDDEN) → requireRole → support mode + non-GET → SUPPORT_READ_ONLY → parse body/query/params ด้วย zod → fn → JSON (status 200/201/204)
2. error → `{error:{code,message,details}}` ตาม docs/spec/vectors/errors.json; zod error → VALIDATION_FAILED + details.fields
3. CSRF: method ≠ GET ต้องมี Origin = APP_BASE_URL (ยกเว้น webhook/cron)
4. rate limit แบบ in-memory token bucket ต่อ key (ip/session) ตามตัวเลขใน 05 §0 → RATE_LIMITED
5. withCustomer: ต้อง session customer ของ branchSlug ใน path; ยังไม่ลงทะเบียน → NOT_REGISTERED (ยกเว้น liff.register)
6. test: ทุกเส้นทาง error ข้างบนด้วย Request จำลอง
