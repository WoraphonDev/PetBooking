5. ข้อความไทยใน messages/th/C-36.json; ป้าย enum ผ่าน enumLabel()
6. component test: render ด้วย mock API (msw หรือ mock ของ api.ts) — ตรวจว่าทุกป้ายฟิลด์ในตาราง 06 ปรากฏ และปุ่มเรียก endpoint ที่ถูกต้อง
