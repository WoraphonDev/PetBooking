## Steps

1. auth/session.ts: สร้าง token 32 bytes (base64url) เก็บ sha256 ใน `session.token_hash`; อายุตาม 02 (staff 30 วัน sliding, customer 30 วัน, admin 12 ชม.); `lookupSession`, `revokeSession`, `revokeAllFor(subject)`
2. auth/password.ts: argon2id ผ่าน `@node-rs/argon2` (memoryCost 19456, timeCost 2, parallelism 1) + ใช้ R-24 (`@app/domain/auth/lockout`)
3. auth/cookies.ts: ชื่อ `sid` (staff) `cid` (customer) `aid` (admin) — HttpOnly, Secure (ยกเว้น dev), SameSite=Lax, Path=/
4. auth/permissions.ts: map endpoint key → roles สร้างจาก docs/spec/vectors/permissions.json (เขียนเป็น TS literal) + `requireRole(ctx, key)`
5. test: permissions.ts เท่ากับ permissions.json ทุก key; session หมดอายุ/revoke; R-24 lock หลัง 5 ครั้ง
