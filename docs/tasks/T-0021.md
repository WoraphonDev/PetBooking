## Contract (คัดจาก 05 — ชื่อฟิลด์/ชนิด/บังคับ ต้องตรงทุกตัว)

**`auth.resetConfirm`** — `POST /api/v1/auth/staff/password-reset/confirm` · สิทธิ์ `public`

Request body:

| field | type | req | maps to | validation |
|---|---|---|---|---|
| `token` | string | ✓ | password_reset.token_hash | token จากลิงก์ (DB เก็บ sha256) |
| `newPassword` | string | ✓ | staff_user.password_hash | R-24 policy |

Response: `204`
Errors: `TOKEN_INVALID`, `PASSWORD_POLICY`
ผลที่ต้องเกิด:
- ตั้ง password_reset.used_at, ลบ session เดิมทั้งหมดของผู้ใช้

## Test cases ที่ต้องมี (integration, PGlite)

**auth.resetConfirm** (POST `/api/v1/auth/staff/password-reset/confirm`)
  - happy path: response ตรง schema `AuthResetConfirmResponse` และค่าที่บันทึกใน DB ตรงกับ 'maps to' ของแต่ละฟิลด์
