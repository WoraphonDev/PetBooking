## Steps

1. log.ts: JSON log (requestId, orgId, key, ms, status) — ห้าม log body/secret
2. health: SELECT 1 → db ok/error; route ต่อกับ service (db error → 503, ok: false) และแก้ `apps/web/test/api/health.test.ts` ให้ตรง 05#ep-health
3. เทสต์ service อยู่ที่ `packages/server/test/services/health/**` (ใช้ vitest config เดิมของ server — ไม่สร้าง config แยก); `packages/server/package.json` แก้ได้เฉพาะเพิ่ม export entry ที่ route ต้องใช้
4. error reporting ใน MVP = `log.ts` level error ไป stdout ของ hosting เท่านั้น — ไม่เพิ่ม SDK/dependency; env `ERROR_REPORT_DSN` (01 §6) สงวนไว้ ยังไม่ใช้ (Q-0012)
5. docs/ops/monitoring.md: ตั้ง uptime monitor ฟรีเรียก /api/health ทุก 5 นาที แจ้งเตือนทางอีเมล/LINE ของทีม
