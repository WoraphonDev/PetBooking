# H-01 · ตั้ง GitHub repo จาก starter kit + กฎ branch

**Milestone** M0 · **Lane** human · **Size** - · **Wave** 1 (ทำพร้อมกันได้กับ task wave เดียวกันใน milestone นี้)  
**Stories** US-13-01 · **Depends on** —

## สิ่งที่ต้องทำ (มนุษย์)

1. สร้าง private repo แล้ว push starter kit ทั้งหมด (รวม pnpm-lock.yaml) เป็น commit แรกบน main
2. Branch protection บน main: require PR, require status check `ci / verify`, require 1 approval, require CODEOWNERS review, ห้าม force push
3. สร้าง labels: `spec-change`, `infra-change`, `human-review`, `agent:claude`, `agent:codex`, `blocked`
4. แก้ `.github/CODEOWNERS` แทน @OWNER ด้วย GitHub handle ของ tech owner (PR label infra-change)
5. เปิด GitHub Actions; ทดสอบ PR ว่าง ๆ ให้ CI เขียว
6. ติดตั้ง Claude Code และ Codex ให้ใช้ repo นี้ (ทั้งคู่อ่าน AGENTS.md อัตโนมัติ)
