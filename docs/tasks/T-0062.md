## Contract (คัดจาก 05 — ชื่อฟิลด์/ชนิด/บังคับ ต้องตรงทุกตัว)

**`imports.create`** — `POST /api/v1/staff/imports` · สิทธิ์ `staff` roles `O`

Request body:

| field | type | req | maps to | validation |
|---|---|---|---|---|
| `kind` | enum:import_kind | ✓ | import_job.kind |  |
| `fileId` | uuid | ✓ | import_job.file_id | kind import_csv, UTF-8 (รองรับ BOM) |

Response: `ImportJobItem` — ดูฟิลด์ DTO ที่ anchor `dto-<Name>` ใน 05
ผลที่ต้องเกิด:
- parse + validate ทุกแถว (R-22 เบอร์, enum, วันที่ dd/mm/yyyy หรือ yyyy-mm-dd, ปี พ.ศ. แปลงอัตโนมัติ) → status ready
- คอลัมน์ CSV ลูกค้า-น้อง: customer_first_name*, customer_last_name, nickname, phone*, pet_name*, species*, breed, sex, birth_date, coat_type, weight_kg, note
- คอลัมน์ CSV บริการ: service_name*, category*, size_code, coat_group, price_baht*, duration_minutes*

## Test cases ที่ต้องมี (integration, PGlite)

**imports.create** (POST `/api/v1/staff/imports`)
  - happy path: response ตรง schema `ImportsCreateResponse` และค่าที่บันทึกใน DB ตรงกับ 'maps to' ของแต่ละฟิลด์

  - effect: คอลัมน์ CSV ลูกค้า-น้อง: customer_first_name*, customer_last_name, nickname, phone*, pet_name*, species*, breed, sex, birth_date, coat_type, weight_kg, note
