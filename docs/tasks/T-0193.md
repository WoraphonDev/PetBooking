# T-0193 · Notification templates (staff, M3): slip_submitted, approval_overdue, booking_cancelled, booking_rescheduled, link_request

**Milestone** M3 · **Lane** notify · **Size** M · **Wave** 1 (ทำพร้อมกันได้กับ task wave เดียวกันใน milestone นี้)  
**Stories** US-05-05, US-07-02, US-11-01, US-11-08 · **Depends on** T-0010, T-0091

## Steps

1. `staff.slip_submitted`: ช่องทาง web_push, ตัวแปร bookingNo, amount, duplicateFlag, ข้อความ: สลิปใหม่ {bookingNo} {amount} {duplicateFlag}
2. `staff.approval_overdue`: ช่องทาง web_push, ตัวแปร bookingNo, waitedMinutes, ข้อความ: ⏰ {bookingNo} รออนุมัติมา {waitedMinutes} นาที
3. `staff.booking_cancelled`: ช่องทาง web_push, ตัวแปร bookingNo, customerName, isLate, ข้อความ: ลูกค้ายกเลิก {bookingNo} ({customerName}) {isLate}
4. `staff.booking_rescheduled`: ช่องทาง web_push, ตัวแปร petName, newDateTime, ข้อความ: ลูกค้าเลื่อนนัด {petName} เป็น {newDateTime}
5. `staff.link_request`: ช่องทาง web_push, ตัวแปร lineName, phone, ข้อความ: {lineName} ขอเชื่อม LINE กับลูกค้าเบอร์ {phone} — ตรวจสอบ
6. LINE: Flex Message แบบเรียบ (ข้อความ + ปุ่มลิงก์ LIFF) + altText = บรรทัดแรก; Web Push: title/body/url; email: subject + text
7. เงิน/วันที่ในข้อความใช้ R-31
