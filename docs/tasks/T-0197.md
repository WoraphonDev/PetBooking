1. หน้าจอ P-01 หน้าลิงก์จองของร้าน: หน้าเว็บสาธารณะจาก QR โปสเตอร์ — พาไปจองใน LINE
2. สร้างทุก section/field ตามตาราง 06 ครบทุกแถว: โหมด (แสดง/กรอก/แก้), แหล่งข้อมูล table.column → ฟิลด์ใน DTO ของ endpoint ที่โหลด, UI/รูปแบบ, กติกา
3. ปุ่ม: แสดงตามเงื่อนไข 'แสดงเมื่อ' และทำตาม 'หลังสำเร็จ'
4. ข้อความไทยใน messages/th/P-01.json; ป้าย enum ผ่าน enumLabel()
5. component test: render ด้วย mock API (msw หรือ mock ของ api.ts) — ตรวจว่าทุกป้ายฟิลด์ในตาราง 06 ปรากฏ และปุ่มเรียก endpoint ที่ถูกต้อง
