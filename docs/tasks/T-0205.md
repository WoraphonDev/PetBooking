## Steps

1. หน้าจอ C-22 ข้อความที่ไม่ได้ส่ง: ข้อความที่ระบบข้าม (โควตาหมด/ไม่ใช่เพื่อน/โหมดประหยัด) ให้ร้านส่งเองในแชท
2. ขอบเขตรอบนี้: สถานะโหมดประหยัดแยกเป็นงานต่อยอดหลังมี API อ่าน policy (Q-0083); คงลิงก์ตั้งค่านโยบาย
3. สร้างทุก section/field ตามตาราง 06 ครบทุกแถว: โหมด (แสดง/กรอก/แก้), แหล่งข้อมูล table.column → ฟิลด์ใน DTO ของ endpoint ที่โหลด, UI/รูปแบบ, กติกา
4. ปุ่ม: แสดงตามเงื่อนไข 'แสดงเมื่อ' และทำตาม 'หลังสำเร็จ'
5. ข้อความไทยใน messages/th/C-22.json; ป้าย enum ผ่าน enumLabel()
6. component test: render ด้วย mock API (msw หรือ mock ของ api.ts) — ตรวจว่าทุกป้ายฟิลด์ในตาราง 06 ปรากฏ และปุ่มเรียก endpoint ที่ถูกต้อง
7. เปิด entry ของหน้าจอนี้ใน shell-console/navigation/<SCREEN-ID>.ts เมื่อ implement แล้ว (Q-0048)
