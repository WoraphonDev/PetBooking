## Contract (คัดจาก 05 — ชื่อฟิลด์/ชนิด/บังคับ ต้องตรงทุกตัว)

**`liff.reportCard`** — `GET /api/v1/liff/{branchSlug}/report-cards/{reportCardId}` · สิทธิ์ `customer`

Response: `ReportCardDetail` — ดูฟิลด์ DTO ที่ anchor `dto-<Name>` ใน 05
ผลที่ต้องเกิด:
- เฉพาะ status sent ของลูกค้าคนนี้; ไม่ส่ง internal fields

**`liff.rate`** — `POST /api/v1/liff/{branchSlug}/report-cards/{reportCardId}/rating` · สิทธิ์ `customer`

Request body:

| field | type | req | maps to | validation |
|---|---|---|---|---|
| `rating` | int | ✓ | report_card.customer_rating | 1–5 |
| `feedback` | string |  | report_card.customer_feedback | ≤ 1000 ถึงร้านเท่านั้น |

Response: `ReportCardDetail` — ดูฟิลด์ DTO ที่ anchor `dto-<Name>` ใน 05
Notify: `staff.low_rating (rating ≤ 3)`
ผลที่ต้องเกิด:
- แสดงปุ่มรีวิว Google ให้ทุกคนเท่ากัน ไม่ขึ้นกับดาว (นโยบาย Google)

**`liff.reviewClick`** — `POST /api/v1/liff/{branchSlug}/report-cards/{reportCardId}/review-click` · สิทธิ์ `customer`

Response: `204`
ผลที่ต้องเกิด:
- report_card.google_review_clicked_at = now (ครั้งแรก)
