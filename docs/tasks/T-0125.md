## Contract (คัดจาก 05 — ชื่อฟิลด์/ชนิด/บังคับ ต้องตรงทุกตัว)

**`admin.supportStart`** — `POST /api/v1/admin/support-sessions` · สิทธิ์ `admin`

Request body:

| field | type | req | maps to | validation |
|---|---|---|---|---|
| `organizationId` | uuid | ✓ | support_access_log.organization_id |  |
| `reason` | string | ✓ | support_access_log.reason | ≥ 10 |
| `ticketRef` | string |  | support_access_log.ticket_ref |  |

Response: `object {redirectUrl}`
Audit: `support.session_start`
Notify: `owner.support_access`
ผลที่ต้องเกิด:
- สร้าง session staff-like ที่ support_access_log_id มีค่า (60 นาที) — ทุก request เขียนถูกปฏิเสธ SUPPORT_READ_ONLY
- แจ้งเจ้าของร้าน

**`admin.supportEnd`** — `POST /api/v1/admin/support-sessions/{supportId}/end` · สิทธิ์ `admin`

Response: `204`
Audit: `support.session_end`

**`admin.feedback`** — `GET /api/v1/admin/feedback` · สิทธิ์ `admin`

Response: `FeedbackItem[]` — ดูฟิลด์ DTO ที่ anchor `dto-<Name>` ใน 05
