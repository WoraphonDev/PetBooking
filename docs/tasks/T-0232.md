## Contract (คัดจาก 05 — ชื่อฟิลด์/ชนิด/บังคับ ต้องตรงทุกตัว)

**`bills.removeLine`** — `DELETE /api/v1/staff/bill-lines/{lineId}` · สิทธิ์ `staff` roles `OF`

Response: `BillDetail` — ดูฟิลด์ DTO ที่ anchor `dto-<Name>` ใน 05
Errors: `BILL_NOT_OPEN`
ผลที่ต้องเกิด:
- บรรทัดที่มาจากใบจองลบไม่ได้ (ให้ยกเลิก child แทน)

**`bills.setDiscount`** — `PATCH /api/v1/staff/bills/{billId}/discount` · สิทธิ์ `staff` roles `OF`

Request body:

| field | type | req | maps to | validation |
|---|---|---|---|---|
| `billDiscountSatang` | int | ✓ | bill.bill_discount_satang | ≤ subtotal |
| `reason` | string |  | bill.bill_discount_reason | บังคับเมื่อ > 0 |

Response: `BillDetail` — ดูฟิลด์ DTO ที่ anchor `dto-<Name>` ใน 05
Errors: `BILL_DISCOUNT_TOO_LARGE`, `DISCOUNT_LIMIT_EXCEEDED`, `REASON_REQUIRED`
Audit: `bill.discount`

**`bills.voidPayment`** — `POST /api/v1/staff/payments/{paymentId}/void` · สิทธิ์ `staff` roles `OF`

Request body:

| field | type | req | maps to | validation |
|---|---|---|---|---|
| `reason` | string | ✓ | payment.void_reason | ≥ 3 |

Response: `BillDetail` — ดูฟิลด์ DTO ที่ anchor `dto-<Name>` ใน 05
Errors: `BILL_NOT_OPEN`, `REASON_REQUIRED`
Audit: `payment.void`
ผลที่ต้องเกิด:
- credit → คืน credit_ledger reason void_reversal
