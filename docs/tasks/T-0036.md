## Steps

1. jobs/schedule.ts: `scheduleJob(tx, {type, runAt, payload, dedupeKey, orgId})` ON CONFLICT DO NOTHING; `cancelJobs(tx, dedupePrefix)`
2. jobs/runner.ts: claim ≤ 50 งานด้วย FOR UPDATE SKIP LOCKED, รันแต่ละงานใน transaction, backoff 2^attempts นาที, ครบ 5 → failed, ปลดล็อก running > 10 นาที
3. jobs/handlers/<job_type>.ts: stub ครบทั้ง 9 type (throw not implemented) + registry ครบ
4. seed งานประจำ (owner_daily_summary ต่อสาขา, care_task_overdue_scan ทุก 15 นาที, recompute_reliability 03:00, package_expiry 00:10, cleanup 04:00) ด้วย dedupe key ตาม 07
5. endpoint `cron.tick`: ตรวจ header x-cron-secret (CRON_FORBIDDEN) → seed → run → dispatch notification queued ค้าง > 1 นาที
6. test: claim ไม่ซ้ำเมื่อรันพร้อมกัน 2 ตัว (PGlite 2 tx), backoff, failed
