## Contract (คัดจาก 05 — ชื่อฟิลด์/ชนิด/บังคับ ต้องตรงทุกตัว)

**`liff.groomSlots`** — `POST /api/v1/liff/{branchSlug}/availability/groom-slots` · สิทธิ์ `customer`

Request body:

| field | type | req | maps to | validation |
|---|---|---|---|---|
| `date` | date | ✓ |  |  |
| `petId` | uuid | ✓ |  | ต้องเป็นน้องของลูกค้า |
| `serviceIds[]` | uuid[] | ✓ |  | online_bookable |
| `addonIds[]` | uuid[] |  |  |  |
| `groomerId` | uuid |  |  |  |
| `sizeTierId` | uuid |  |  | ลูกค้าเลือกเองเมื่อไม่มีน้ำหนัก |
