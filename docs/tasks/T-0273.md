## Contract (คัดจาก 05 — ชื่อฟิลด์/ชนิด/บังคับ ต้องตรงทุกตัว)

**`stays.today`** — `GET /api/v1/staff/stays` · สิทธิ์ `staff` roles `OFS`

Query:

| field | type | req | maps to | validation |
|---|---|---|---|---|
| `date` | date | ✓ |  |  |
| `type` | enum |  |  | arrivals \| departures \| in_house |

Response: `StayCard[]` — ดูฟิลด์ DTO ที่ anchor `dto-<Name>` ใน 05

**`stays.get`** — `GET /api/v1/staff/stays/{stayId}` · สิทธิ์ `staff` roles `OFS`

Response: `StayDetail` — ดูฟิลด์ DTO ที่ anchor `dto-<Name>` ใน 05

**`stays.signAgreement`** — `POST /api/v1/staff/stays/{stayId}/agreement` · สิทธิ์ `staff` roles `OF`

Request body:

| field | type | req | maps to | validation |
|---|---|---|---|---|
| `signerName` | string | ✓ | consent_document.signer_name |  |
| `signatureFileId` | uuid | ✓ | consent_document.signature_file_id | PNG |
| `emergencyVetLimitSatang` | int |  | consent_document.emergency_vet_limit_satang | ≥ 0 |

Response: `StayDetail` — ดูฟิลด์ DTO ที่ anchor `dto-<Name>` ใน 05
ผลที่ต้องเกิด:
- body_snapshot = branch_policy.boarding_agreement_text
- เก็บเป็น immutable — เซ็นใหม่ = record ใหม่

## Test cases ที่ต้องมี (integration, PGlite)

**stays.today** (GET `/api/v1/staff/stays`)
  - happy path: response ตรง schema `StaysTodayResponse` และค่าที่บันทึกใน DB ตรงกับ 'maps to' ของแต่ละฟิลด์
  - ฟิลด์บังคับขาด/ผิดรูปแบบ → `VALIDATION_FAILED`
  - ข้อมูลของ organization อื่น → `NOT_FOUND`
**stays.get** (GET `/api/v1/staff/stays/{stayId}`)
  - happy path: response ตรง schema `StaysGetResponse` และค่าที่บันทึกใน DB ตรงกับ 'maps to' ของแต่ละฟิลด์
  - ฟิลด์บังคับขาด/ผิดรูปแบบ → `VALIDATION_FAILED`
  - ข้อมูลของ organization อื่น → `NOT_FOUND`
**stays.signAgreement** (POST `/api/v1/staff/stays/{stayId}/agreement`)
  - happy path: response ตรง schema `StaysSignAgreementResponse` และค่าที่บันทึกใน DB ตรงกับ 'maps to' ของแต่ละฟิลด์
  - ฟิลด์บังคับขาด/ผิดรูปแบบ → `VALIDATION_FAILED`
  - role staff → `FORBIDDEN`
  - ข้อมูลของ organization อื่น → `NOT_FOUND`
  - effect: body_snapshot = branch_policy.boarding_agreement_text
  - effect: เก็บเป็น immutable — เซ็นใหม่ = record ใหม่
