## Steps

1. notify/keys.ts: union ของ template key ทั้ง 38 ใน 07 + payload type ต่อ key (ตัวแปรในคอลัมน์ 'ตัวแปร')
2. notify/templates/<key>.ts: สร้าง **stub ครบทุก key** (`render(payload) => { text }` คืนข้อความจากคอลัมน์ 'ข้อความ' แบบแทนตัวแปรตรง ๆ) — task template ภายหลังแก้เฉพาะไฟล์ของตัวเอง
3. notify/enqueue.ts: `enqueueNotification(tx, ctx, {key, recipient, payload, dedupeKey})` insert notification queued (ON CONFLICT dedupe_key DO NOTHING) + month_key ท้องถิ่น
4. notify/dispatch.ts: หลัง commit ส่งแถว queued: เลือกช่องทาง R-19, โควตา R-18 (นับ notification เดือนนี้), adapters `LineSender`, `WebPushSender`, `EmailSender` เป็น interface + fake ใน test (implementation จริงอยู่ใน task integrations)
5. test: dedupe, skip reasons ทุกแบบ, economy mode, quota 80% เตือนเจ้าของครั้งเดียว
