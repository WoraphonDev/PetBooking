## Contract (คัดจาก 05 — ชื่อฟิลด์/ชนิด/บังคับ ต้องตรงทุกตัว)

**`admin.login`** — `POST /api/v1/auth/admin/login` · สิทธิ์ `public`

Request body:

| field | type | req | maps to | validation |
|---|---|---|---|---|
| `email` | string | ✓ | platform_admin.email |  |
| `password` | string | ✓ | platform_admin.password_hash |  |

Response: `object {admin}`
Errors: `INVALID_CREDENTIALS`, `ACCOUNT_LOCKED`
ผลที่ต้องเกิด:
- session 12 ชม. cookie `aid`

**`admin.orgs`** — `GET /api/v1/admin/organizations` · สิทธิ์ `admin`

Response: `OrgListItem[]` — ดูฟิลด์ DTO ที่ anchor `dto-<Name>` ใน 05

**`admin.updateOrg`** — `PATCH /api/v1/admin/organizations/{orgId}` · สิทธิ์ `admin`

Request body:

| field | type | req | maps to | validation |
|---|---|---|---|---|
| `status` | enum:org_status | ✓ | organization.status |  |

Response: `OrgListItem` — ดูฟิลด์ DTO ที่ anchor `dto-<Name>` ใน 05
ผลที่ต้องเกิด:
- suspended → ทุก session ของร้านถูกปฏิเสธ (403) ยกเว้น admin
