## Steps

1. หน้าจอ A-01 เข้าสู่ระบบ (ร้าน): พนักงานเข้าสู่ระบบด้วยอีเมล หรือปุ่ม LINE (สำหรับช่าง)
2. เพิ่มเฉพาะส่วน/ปุ่มที่ใช้ endpoint: auth.staffLine
3. ขอบเขตรอบนี้: เพิ่มส่วนที่ใช้ endpoint ของ M2
4. สร้างทุก section/field ตามตาราง 06 ครบทุกแถว: โหมด (แสดง/กรอก/แก้), แหล่งข้อมูล table.column → ฟิลด์ใน DTO ของ endpoint ที่โหลด, UI/รูปแบบ, กติกา
5. ปุ่ม: แสดงตามเงื่อนไข 'แสดงเมื่อ' และทำตาม 'หลังสำเร็จ'
6. ข้อความไทยใน messages/th/A-01.json; ป้าย enum ผ่าน enumLabel()
7. component test: render ด้วย mock API (msw หรือ mock ของ api.ts) — ตรวจว่าทุกป้ายฟิลด์ในตาราง 06 ปรากฏ และปุ่มเรียก endpoint ที่ถูกต้อง
