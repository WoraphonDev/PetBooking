## Steps

1. `apps/web/package.json` name `@app/web`, scripts dev/build/start/typecheck/test; deps: next, react, react-dom, tailwindcss, @tailwindcss/postcss, next-intl, zod (เวอร์ชันล่าสุดที่ pin ตรงตัว)
2. next.config.ts: `transpilePackages: ['@app/contracts','@app/domain','@app/server','@app/db']`, `output: 'standalone'`
3. route groups ว่าง (auth) (public) (console) (staff) (liff) (admin) แต่ละอันมี layout.tsx เปล่า — **ห้ามสร้าง page.tsx ที่ไม่อยู่ใน 06**

5. ฟอนต์ไทย: next/font/google `Noto_Sans_Thai` + `IBM_Plex_Sans_Thai` fallback
6. `app/api/health/route.ts` (endpoint `health`): GET → `{ ok: true, db: 'unknown', version: process.env.NEXT_PUBLIC_APP_VERSION }` (db check เพิ่มใน INF-MON)
