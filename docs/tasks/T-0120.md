## Contract (คัดจาก 05 — ชื่อฟิลด์/ชนิด/บังคับ ต้องตรงทุกตัว)

**`groom.addSurcharge`** — `POST /api/v1/staff/groom-appointments/{appointmentId}/surcharges` · สิทธิ์ `staff` roles `OF`

Request body:

| field | type | req | maps to | validation |
|---|---|---|---|---|
| `surchargeTypeId` | uuid |  | appointment_surcharge.surcharge_type_id |  |
| `name` | string | ✓ | appointment_surcharge.name | 1–60 |
| `amountSatang` | int | ✓ | appointment_surcharge.amount_satang | > 0 |
| `reason` | string | ✓ | appointment_surcharge.reason | ≥ 3 ลูกค้าเห็นในบิล |

Response: `AppointmentCard` — ดูฟิลด์ DTO ที่ anchor `dto-<Name>` ใน 05
ผลที่ต้องเกิด:
- อัปเดต groom_appointment.surcharge_total_satang; บิลที่ open อยู่ → เพิ่ม bill_line surcharge

**`groom.removeSurcharge`** — `DELETE /api/v1/staff/appointment-surcharges/{surchargeId}` · สิทธิ์ `staff` roles `OF`

Response: `AppointmentCard` — ดูฟิลด์ DTO ที่ anchor `dto-<Name>` ใน 05

**`groom.jobCard`** — `GET /api/v1/staff/groom-appointments/{appointmentId}/job-card` · สิทธิ์ `staff` roles `OFS`

Response: `JobCard` — ดูฟิลด์ DTO ที่ anchor `dto-<Name>` ใน 05
