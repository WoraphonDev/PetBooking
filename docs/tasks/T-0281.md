## Test cases ที่ต้องมี (integration, PGlite)

**careTasks.list** (GET `/api/v1/staff/care-tasks`)
  - happy path: response ตรง schema `CareTasksListResponse` และค่าที่บันทึกใน DB ตรงกับ 'maps to' ของแต่ละฟิลด์
  - ฟิลด์บังคับขาด/ผิดรูปแบบ → `VALIDATION_FAILED`
  - ข้อมูลของ organization อื่น → `NOT_FOUND`
**careTasks.done** (POST `/api/v1/staff/care-tasks/{taskId}/done`)
  - happy path: response ตรง schema `CareTasksDoneResponse` และค่าที่บันทึกใน DB ตรงกับ 'maps to' ของแต่ละฟิลด์
  - ฟิลด์บังคับขาด/ผิดรูปแบบ → `VALIDATION_FAILED`
  - ข้อมูลของ organization อื่น → `NOT_FOUND`
  - state: `care_task:pending→done` + insert booking_event (ถ้าเป็น booking/child) + สถานะต้นทางผิด → `INVALID_TRANSITION`
  - effect: done_at = now, done_by = ผู้ใช้
**careTasks.skip** (POST `/api/v1/staff/care-tasks/{taskId}/skip`)
  - happy path: response ตรง schema `CareTasksSkipResponse` และค่าที่บันทึกใน DB ตรงกับ 'maps to' ของแต่ละฟิลด์
  - ฟิลด์บังคับขาด/ผิดรูปแบบ → `VALIDATION_FAILED`
  - ข้อมูลของ organization อื่น → `NOT_FOUND`
  - state: `care_task:pending→skipped` + insert booking_event (ถ้าเป็น booking/child) + สถานะต้นทางผิด → `INVALID_TRANSITION`
