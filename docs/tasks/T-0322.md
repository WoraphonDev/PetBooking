## Contract (คัดจาก 05 — ชื่อฟิลด์/ชนิด/บังคับ ต้องตรงทุกตัว)

**`auth.invitePreview`** — `GET /api/v1/auth/staff/invite` · สิทธิ์ `public`

Query:

| field | type | req | maps to | validation |
|---|---|---|---|---|
| `token` | string | ✓ | staff_invite.token_hash | token จากลิงก์ |

Response: `InvitePreview` — ดูฟิลด์ DTO ที่ anchor `dto-<Name>` ใน 05
Errors: `TOKEN_INVALID`
ผลที่ต้องเกิด:
- token ไม่พบ/หมดอายุ/ใช้แล้ว → TOKEN_INVALID; ไม่สร้าง session
