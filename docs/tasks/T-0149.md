## Steps

1. crypto.ts: AES-256-GCM encrypt/decrypt ด้วย APP_ENCRYPTION_KEY (iv สุ่มต่อค่า, เก็บ `v1:iv:tag:cipher` base64)
2. line/messaging.ts: push/reply ผ่าน `@line/bot-sdk` ด้วย token ที่ถอดรหัสจาก line_channel; retry 3 ครั้งเฉพาะ 5xx; 401 → line_channel.status error
3. line/idtoken.ts: verify ID token ที่ https://api.line.me/oauth2/v2.1/verify (client_id = login_channel_id) คืน sub/name/picture
4. line/signature.ts: HMAC-SHA256 base64 เทียบแบบ timingSafeEqual
5. LINE_FAKE=1 (ห้ามใน production): fake sender เก็บข้อความใน memory + fake idtoken รูปแบบ `fake:<userId>:<name>` สำหรับ dev/E2E
6. ต่อ LineSender เข้ากับ dispatcher (reply token store ตาม R-19 / SP-03)
