# ADR-005 — Web Push บนอุปกรณ์จริงของร้าน (แทน LINE Notify)

- สถานะ: **proposed** — กรอกผลใน task human ของ M2 ก่อนนำร่อง
- บริบท: LINE Notify ปิดบริการแล้ว → แจ้งเตือนพนักงานใช้ Web Push (VAPID, ฟรี) + อีเมลสำรอง
- iOS: Web Push ทำงานเฉพาะเมื่อ "Add to Home Screen" (iOS/iPadOS 16.4 ขึ้นไป)
