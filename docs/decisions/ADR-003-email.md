# ADR-003 — ผู้ให้บริการอีเมล (SMTP)

- สถานะ: **proposed** — ตัดสินใน task H-02
- ใช้กับ: คำเชิญพนักงาน, รีเซ็ตรหัสผ่าน, สรุปรายวันถึงเจ้าของ (ปริมาณน้อยมาก < 50 ฉบับ/วันในช่วงนำร่อง)

## ทางเลือก
| | ข้อดี | ข้อเสีย |
|---|---|---|
| A. บริการ transactional email แพ็กฟรี (เช่น Resend / Brevo) | deliverability ดี, ตั้ง SPF/DKIM กับโดเมนได้ | มีเพดานต่อวัน/เดือน, ต้องยืนยันโดเมน |
| B. SMTP ของ Google Workspace/Gmail | ตั้งง่าย | เพดานต่อวัน, ใช้ app password, ไม่เหมาะกับระบบ |

## ข้อเสนอ
**A** ผ่าน SMTP (`SMTP_URL`) — โค้ดใช้ nodemailer จึงเปลี่ยนผู้ให้บริการได้โดยแก้ env อย่างเดียว · ตรวจเพดานฟรีจริงก่อนเลือก
