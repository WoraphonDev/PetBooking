# ร่างโครงเอกสารกฎหมาย PJ-8 (สำหรับตรวจแก้โดยผู้ดูแลด้านกฎหมาย)

> **สถานะ: ร่างโครงเท่านั้น — ห้ามเผยแพร่จนกว่านักกฎหมายจะตรวจและเติมเนื้อหาจริง** (Q-0045)
> ไฟล์จริงต้องวางที่ `apps/web/content/legal/{privacy_notice,terms_of_service,dpa}.2026-10-01.md` ตาม 10#legal-docs

## 1. ประกาศความเป็นส่วนตัว (privacy_notice) — แสดงให้ลูกค้าของร้านตอนลงทะเบียนใน LINE (L-01)

บทบาท: **ร้าน = ผู้ควบคุมข้อมูล** · **[ชื่อบริษัทผู้ให้บริการ PJ-8] = ผู้ประมวลผลข้อมูล** (?)

1. **ผู้ควบคุมข้อมูลและช่องทางติดต่อ** — ชื่อร้าน/สาขา (ดึงจากระบบ), ช่องทางติดต่อร้าน, ผู้ประมวลผล [ชื่อ ที่อยู่ อีเมล]
2. **ข้อมูลที่เก็บ**
   - ข้อมูลเจ้าของ: ชื่อ, เบอร์โทร, LINE user id/ชื่อที่แสดง, อีเมล (ถ้ามี), ที่อยู่ (ถ้ามี)
   - ข้อมูลสัตว์เลี้ยง: ชื่อ, ชนิด, สายพันธุ์, น้ำหนัก, อายุ, ประวัติวัคซีน, ข้อสังเกตสุขภาพ/พฤติกรรม, รูปภาพ
   - ข้อมูลการใช้บริการ: นัดหมาย, การเข้าพัก, บิล/การชำระเงิน, สลิปโอนเงิน, สมุดพก (report card), คะแนน/ความเห็น
   - ข้อมูลทางเทคนิค: [log การใช้งาน, IP?] (?)
3. **วัตถุประสงค์และฐานทางกฎหมาย** (PDPA ม.24)
   - ให้บริการตามสัญญา (นัด/ฝาก/ดูแล/รับชำระเงิน) — ฐานสัญญา
   - แจ้งเตือนนัด/สถานะผ่าน LINE — ฐานสัญญา
   - ข่าวสาร/โปรโมชัน, เตือนครบรอบอาบน้ำ — ฐานความยินยอม (ถอนได้) (?)
   - ใช้รูปสัตว์เลี้ยงในสมุดพก/สื่อของร้าน — ฐานความยินยอม (`photo_consent`)
   - เก็บบัญชี/ใบเสร็จตามกฎหมาย — ฐานหน้าที่ตามกฎหมาย
4. **ระยะเวลาเก็บ** — ข้อมูลบัญชี/ใบเสร็จ [x ปีตามกฎหมายบัญชี/ภาษี] (?) · ข้อมูลลูกค้าอื่น [จนกว่าจะขอลบ หรือ x ปีหลังใช้บริการครั้งสุดท้าย] (?) · สลิป/รูป [x เดือน] (?)
5. **การเปิดเผยข้อมูล** — ผู้ให้บริการระบบ (PJ-8), ผู้ให้บริการโครงสร้างพื้นฐาน [hosting/DB/storage/อีเมล ตาม ADR-002..004], LINE Corporation (ช่องทางสื่อสาร); การส่งข้อมูลไปต่างประเทศ [ถ้ามี — ระบุประเทศและมาตรการ] (?)
6. **สิทธิของเจ้าของข้อมูล** — ขอเข้าถึง/รับสำเนา, แก้ไข, ลบ, คัดค้าน, ระงับ, โอนย้าย, ถอนความยินยอม, ร้องเรียน สคส. — ยื่นคำขอได้ในเมนู LINE (คำขอ `access` / `delete` ตาม US-13-08) ร้านตอบภายใน [30 วัน] (?)
7. **ความปลอดภัย** — การเข้ารหัสระหว่างส่ง, จำกัดสิทธิ์พนักงานตามบทบาท, บันทึกการเข้าถึง (audit log), ทีมผู้ให้บริการเข้าดูได้เฉพาะเมื่อร้านอนุญาต/เพื่อช่วยเหลือ (support mode มีบันทึก)
8. **การเปลี่ยนแปลงประกาศ** — วันที่มีผล [2026-10-01], แจ้งผ่าน LINE เมื่อมีการเปลี่ยนแปลงสาระสำคัญ

## 2. ข้อกำหนดการใช้บริการ (terms_of_service) — ร้านยอมรับตอน owner รับคำเชิญครั้งแรก (A-04)

1. คู่สัญญาและคำนิยาม (ผู้ให้บริการ, ร้าน, ผู้ใช้, ลูกค้าของร้าน)
2. ขอบเขตบริการ (ระบบจัดการนัด/ฝาก/บิล, LINE OA ของร้าน, PWA พนักงาน) และระยะทดลอง/pilot [เงื่อนไขพิเศษ?] (?)
3. บัญชีผู้ใช้และความรับผิดชอบของร้าน (รักษารหัสผ่าน, สิทธิ์พนักงาน, ความถูกต้องของข้อมูล, ใช้ LINE OA ของร้านเองตามนโยบาย LINE)
4. ค่าบริการ การชำระ และการยกเลิก [ฟรีช่วง pilot / แพ็กเกจ] (?)
5. การรับเงินจากลูกค้า — ระบบไม่ได้เป็นตัวกลางรับเงิน (PromptPay/โอนเข้าบัญชีร้านโดยตรง); การตรวจสลิปเป็นการช่วยตรวจเบื้องต้น ร้านต้องยืนยันเอง
6. ข้อมูลและทรัพย์สินทางปัญญา (ข้อมูลเป็นของร้าน; การส่งออก CSV; การลบเมื่อเลิกใช้ [x วัน]) (?)
7. ระดับบริการและการหยุดให้บริการ/บำรุงรักษา [ไม่มี SLA ช่วง pilot?] (?)
8. ข้อจำกัดความรับผิด และการชดใช้ (?)
9. การระงับ/ยกเลิกบัญชี (ฝ่าฝืนข้อกำหนด, ไม่ชำระ)
10. กฎหมายที่ใช้บังคับ (ไทย) และการระงับข้อพิพาท (?)
11. การเปลี่ยนแปลงข้อกำหนดและวันมีผล

## 3. ข้อตกลงการประมวลผลข้อมูล (dpa) — ระหว่างร้าน (ผู้ควบคุม) กับผู้ให้บริการ (ผู้ประมวลผล)

1. คู่สัญญา บทบาท และวัตถุประสงค์การประมวลผล (เฉพาะเพื่อให้บริการตามข้อกำหนด)
2. ประเภทข้อมูลและเจ้าของข้อมูล (อ้างอิงข้อ 1.2)
3. หน้าที่ผู้ประมวลผล (PDPA ม.40): ทำตามคำสั่งร้าน, รักษาความลับ, มาตรการความปลอดภัย, แจ้งเหตุละเมิดภายใน [72 ชม.] (?), ช่วยร้านตอบคำขอใช้สิทธิ์, ลบ/คืนข้อมูลเมื่อสิ้นสุดสัญญา
4. ผู้ประมวลผลช่วง (sub-processors): [hosting, DB, storage, อีเมล, LINE] — การแจ้งเมื่อเปลี่ยน (?)
5. การส่งข้อมูลไปต่างประเทศและมาตรการคุ้มครอง (?)
6. การเข้าถึงโดยทีมช่วยเหลือ (support mode): อ่านอย่างเดียว, มีเหตุผลและบันทึก, แจ้งเจ้าของร้าน (`owner.support_access`)
7. การตรวจสอบ (audit) และหลักฐานการปฏิบัติตาม (?)
8. ระยะเวลาและการสิ้นสุด, การลบข้อมูล [x วัน] (?)
9. ความรับผิด (อ้างอิงข้อกำหนดการใช้บริการ) (?)

### สิ่งที่ต้องตัดสินก่อนเขียนเนื้อหาจริง
- ชื่อนิติบุคคลผู้ให้บริการ ที่อยู่ ช่องทางติดต่อ DPO (ถ้ามี)
- ผู้ให้บริการโครงสร้างพื้นฐานจริง (ADR-002..004 ยังเป็น proposed) และประเทศที่เก็บข้อมูล
- ระยะเวลาเก็บแต่ละประเภท และฐานกฎหมายของข้อความการตลาด/รูปภาพ
- เงื่อนไข pilot (ค่าบริการ, SLA, การลบข้อมูลเมื่อเลิกใช้)
